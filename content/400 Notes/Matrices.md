# Zero Matrices
- A **zero matrix** is a matrix in which all of the entries are \[0\]. Some examples are given below.

> \[3\times 3\] zero matrix: \[\qquad O_{3\times 3}=\left[\begin{array}{rrr}0 & 0&0  
> \\ 0 & 0&0 \\ 0 & 0&0 \end{array}\right]\]

> \[2\times 4\] zero matrix: \[\qquad O_{2\times 4}=\left[\begin{array}{rrrr}0 & 0 &0&0  
> \\ 0 & 0&0&0 \end{array}\right]\]

A zero matrix is indicated by \[O\], and a subscript can be added to indicate the dimensions of the matrix if necessary.

# Addition
## Properties of Addition
|Property|Example|
|---|---|
|**Commutative property of addition**|\[{A}+{B}={B}+{A}\]|
|**Associative property of addition**|\[{A}+({B}+{C})=({A}+{B})+{C}\]|
|**Additive identity property**|For any matrix \[A\], there is a unique matrix \[O\] such that \[A+O=A\].|
|**Additive inverse property**|For each \[A\], there is a unique matrix \[-A\] such that \[A+(-A)=O\].|
|**Closure property of addition**|\[A+B\] is a matrix of the same dimensions as \[A\] and \[B\].|
# Multiplication
## Properties of Multiplication
| Property                                   | Example                                             |
| ------------------------------------------ | --------------------------------------------------- |
| **Associative property of multiplication** | \[(cd)A=c(dA)\]                                     |
| **Distributive properties**                | \[c(A+B)=cA+cB\]                                    |
|                                            | \[(c+d)A=cA+dA\]                                    |
| **Multiplicative identity property**       | \[1 A=A\]                                           |
| **Multiplicative properties of zero**      | \[0\cdot A=O\]                                      |
|                                            | \[c\cdot O=O\]                                      |
| **Closure property of multiplication**     | \[cA\] is a matrix of the same dimensions as \[A\]. |
|                                            |                                                     |
