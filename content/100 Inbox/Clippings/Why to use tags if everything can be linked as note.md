Because YAML is MUCH easier to manage than a bunch of linked notes. 

You can also nest them. I'm a college student and have a tag structure that looks something like this:
```

#school/subject/science/astronomy
#school/subject/science/biology
#school/subject/math/matrices
#school/work

```
If I know a file I need to search for is from a science course, I can just search ```
```#school/subject/science
```

 and comb through the results to find the file.

With linked notes, you need a new note for every subject.

Notes are for information, tags are for searching information. Keeping metadata and actual data separate makes things MUCH easier.

You can attach a note to a tag, called a "tagpage." This comes up if you cmd+click (or whatever you got) a tag. This is GREAT for providing general info about a subject and explaining the tag's use. I believe from your original post that you might like this use of tags.

Edit: I learned that Reddit uses markdown, and that they consider a pound sign with no space a header.

Double edit afterthought: If you set a page alias to a tag, that makes it the tagpage for that tag.

`Yes, nested tags are great! I also use them with the auto note mover, so for example anything that starts with #Medical/… or #Health/… or #Exercise/… gets automatically added to the appropriate folder.`
